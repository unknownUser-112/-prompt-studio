Status: documented Phase-1 baseline debt; not V600 target behavior

Authoritative artifact:
`reference/v500.6.11/Prompt-Studio-V500.6.11-Binding-Selfie-Open-Garment-State.html`

Authoritative report:
`reference/v500.6.11/Prompt-Studio-V500.6.11-Test-Results.json`

The reference artifacts remain byte-identical. Their approved manifests and
checksums are not changed by these findings.

## Approved baseline findings

| Gate code | Evidence in V500.6.11 | V600 treatment |
|---|---|---|
| `REFERENCE_VERSION_METADATA_STALE` | The released HTML still renders V500.6.10 header metadata. | `V600_VERSION_METADATA_STALE` blocks a V600 artifact. |
| `REFERENCE_EXPORT_FILENAME_STALE` | `staticIntegrity.checks.exportFilename` is `false`; the export path still uses a V500.6.10 filename. | `V600_EXPORT_FILENAME_INVALID` blocks a V600 artifact. |
| `REFERENCE_DUPLICATE_RENDERED_IDS` | `staticIntegrity.checks.noDuplicateStaticIds` is `false`; the static rendered-template IDs `prompt` and `copy` are repeated. | `V600_DUPLICATE_RENDERED_IDS` blocks a V600 artifact. |

These four findings are classifications of the fixed V500.6.11 baseline, not
waivers that apply to V600. The baseline command succeeds only when it detects
this exact approved debt set.

## Executable gates

`scripts/verify-source-integrity.mjs` validates the fixed reference-debt set in
`--baseline` mode. The approved duplicate-ID debt is exactly the static literal
set `copy` and `prompt`; interpolated IDs such as `${id}` do not count as
static duplicates. Missing or additional baseline debt IDs fail the gate.

Its V600 mode rejects every V500 version in visible markup and direct static
DOM sinks such as `textContent`, `innerText`, `innerHTML`,
`insertAdjacentHTML`, and `document.write`, including strings reached through
local `const` aliases. Technical reference paths and migration values outside
visible sinks remain allowed. The exact build metadata values are app version
`V600.0.0-Phase1-Foundation`, database schema `1`, and plugin API `1`.

Static export filenames must match
`prompt-studio-v600(?:-[a-z0-9]+)*\.json`. The gate resolves local constant
aliases used by real `.download`/`setAttribute("download", ...)` sinks and
documented export/download-name constants. Dynamic/user-provided filenames and
unrelated object fields such as `{ filename: "notes.json" }` are not classified
as export contracts. V600 mode also rejects duplicate rendered IDs, unused
exports using TypeScript AST analysis, and open implementation markers.

Release mode is intentionally exclusive: `--release` cannot be combined with
`--baseline` or path overrides. It uses these fixed defaults:

- artifact: `dist/Prompt-Studio-V600.0.0-Phase1-Foundation.html`
- source root: `src`
- iPhone report: `docs/reports/phase1-iphone-viewer.md`

The Markdown report must record `PASS`, a physical iPhone model, dotted iOS
version, HTML Viewer name and dotted version, PASS results for Safari and the
HTML Viewer, and PASS interaction checks for App Start, Wizard Steps 1-10, New
Project Dialog, Profiles, Prompt Output, Import, Export, and Focus After Dialog
Close. Because Task 19 permits only this Markdown report and no additional
screenshot files, Safari and HTML Viewer evidence must each be an embedded
Markdown `data:image/...;base64,...` image. Only strict PNG, JPEG, or WebP data
whose decoded bytes match the declared image magic bytes is accepted. The two
decoded payload hashes must differ. External, protocol-relative, absolute,
FTP, and dead local paths are rejected, as are missing, empty, malformed,
placeholder, simulator, or failed evidence. Every such failure is reported as
`V600_IPHONE_EVIDENCE_INVALID`.

`scripts/verify-module-boundaries.mjs` consumes an esbuild metafile (generated
from the bootstrap entry point unless one is supplied), requires exactly one
composition entry point and requires it to be exactly `src/bootstrap/index.ts`,
validates the actual module edges, rejects forbidden layer imports, and rejects
cycles. Type-only imports removed by esbuild do not create false runtime edges.

`scripts/verify-csp.mjs` parses quoted and browser-valid unquoted attributes in
the final HTML CSP meta policy. Duplicate names are rejected regardless of
quoting (including duplicate `content`) as `CSP_DUPLICATE_ATTRIBUTE`;
malformed/unparsed CSP-meta attributes fail closed as
`CSP_META_ATTRIBUTE_SYNTAX_INVALID`. The gate requires the Phase-1 directives
and rejects network-capable sources.

Run the Work-package A gates with:

```bash
npx vitest run tests/contracts/reference-debt.contract.test.ts
node scripts/verify-source-integrity.mjs --baseline
node scripts/verify-module-boundaries.mjs --bootstrap-only
node scripts/verify-csp.mjs dist/Prompt-Studio-V600.0.0-Phase1-Foundation.html
```

The Task-22 release gate is:

```bash
node scripts/verify-source-integrity.mjs --release
```
