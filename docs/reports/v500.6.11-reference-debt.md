## Approved baseline findings

| `REFERENCE_EXPORT_FILENAME_STALE` | `staticIntegrity.checks.exportFilename` is `false`; the export path still uses a V500.6.10 filename. | `V600_EXPORT_FILENAME_STALE` blocks a V600 artifact. |
| `REFERENCE_DUPLICATE_RENDERED_IDS` | `staticIntegrity.checks.noDuplicateStaticIds` is `false`; alternate rendered templates repeat IDs such as `prompt` and `copy`. | `V600_DUPLICATE_RENDERED_IDS` blocks a V600 artifact. |

These four findings are classifications of the fixed V500.6.11 baseline, not
waivers that apply to V600. The baseline command succeeds only when it detects
this exact approved debt set.

## Executable gates

`scripts/verify-source-integrity.mjs` validates the fixed reference-debt set in
`--baseline` mode. Its V600 mode rejects stale version/export metadata,
duplicate rendered IDs, missing positive real-mobile coverage, unused exports,
and open implementation markers.

`scripts/verify-module-boundaries.mjs` consumes an esbuild metafile (generated
from the bootstrap entry point unless one is supplied), validates the actual
module edges, rejects forbidden layer imports, and rejects cycles. Type-only
imports removed by esbuild do not create false runtime edges.

`scripts/verify-csp.mjs` parses the final HTML CSP meta policy, requires the
Phase-1 directives, and rejects network-capable sources.

Run the Work-package A gates with:

```bash
npx vitest run tests/contracts/reference-debt.contract.test.ts
node scripts/verify-source-integrity.mjs --baseline
node scripts/verify-module-boundaries.mjs --bootstrap-only
node scripts/verify-csp.mjs dist/Prompt-Studio-V600.0.0-Phase1-Foundation.html
```
